# ERP Mini Frontend

Frontend MVP en React + Vite para el flujo principal del ERP:

1. Login
2. Alta de material maestro
3. Entrada de materia prima por lote
4. Creación de Work Orders

## Ejecutar

```bash
cd frontend
npm install
npm run dev
```

## Variables de entorno opcionales

```bash
VITE_API_BASE_URL=http://localhost:8000/api
```

Si no se define, el frontend usa `http://localhost:8000/api`.
